FAQ

よくあるご質問

Ride Metricsは無料ですか？

はい、無料でご利用いただけます。課金機能はありません。

計測データはどこに保存されますか？

計測データはまずご利用の端末内に保存され、当方のサーバーや広告・アクセス解析事業者等の第三者へ送信されることはありません。 詳しくはプライバシーポリシーをご覧ください。

ヘルスケア・カレンダー連携は必須ですか？

いいえ、どちらも任意の機能です。設定でそれぞれ有効にした場合のみ、ワークアウトのヘルスケアへの保存、ライド要約のカレンダーへの登録が行われます。

ライド計測中はなぜ位置情報の「Appの使用中は許可」が必要なのですか？

走行ルート・速度を計測するために使用します。「Appの使用中は許可」を選んでいただければ、ライド計測中は画面ロック時やアプリがバックグラウンドの状態でも計測を継続できます（「常に許可」は不要です）。計測を終了すれば、それ以降の位置情報は取得しません。

対応OSバージョンを教えてください。

最新のiOSでのご利用を推奨しています。対応バージョンはApp Store掲載ページでご確認ください。

ライドの記録を削除すると元に戻せますか？

いいえ、アプリ内のライド削除操作は元に戻せません（アプリ本体の機能による復元はできません）。 ヘルスケア・カレンダーと同期済みの場合は、削除時にそれぞれの連携先データも削除するか個別に確認されます。

計測データを他のサービスに移せますか？

ライドごとにCSV・GPX形式でエクスポートし、共有シートから他のアプリ・サービスへ送信できます。
