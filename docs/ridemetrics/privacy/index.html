Ride Metrics
プライバシーポリシー

カトレアテック（以下「当方」）が提供するiOSアプリ「Ride Metrics」（以下「本アプリ」）における、 個人情報・端末情報の取り扱いについて説明します。

1. 基本方針

本アプリは自転車ライドの走行ルート・速度・高度・消費カロリー等を計測・記録するアプリです。 計測データはまず本アプリを利用する端末内に保存され、当方が運営するサーバーや広告・アクセス解析事業者等の第三者へ送信することはありません。 本アプリには広告SDK・アクセス解析SDK・トラッキング目的のSDKは組み込まれていません。

ただし、次のとおり利用者ご自身が明示的に機能を有効にした場合に限り、端末外（Apple各サービス・利用者が指定した共有先）にもデータが保存・送信されます。詳細は各節を参照してください。

  • ヘルスケア連携を有効にした場合: 計測したワークアウトをApple ヘルスケアへ書き込み保存し、カロリー計算のため体重をヘルスケアから読み取ります（2節）
  • カレンダー連携を有効にした場合: ライド要約がカレンダーへ登録され、ご利用のカレンダー設定によってはiCloud等へ同期され得ます（2節）
  • CSV/GPXエクスポートを利用した場合: 出力したファイルを共有した先（3節）

2. アクセスする端末内情報と利用目的

本アプリは、次の情報について、それぞれの機能を有効にした場合に限りアクセスします。いずれの情報も当方サーバーや広告・解析事業者等の第三者へは送信せず、端末内での計測・表示、および利用者が有効にした任意連携先（Appleのヘルスケア／カレンダー）への保存にのみ用います。

位置情報

走行ルート・速度・高度を計測するために使用します。ライド計測中は、画面ロック時やバックグラウンドでも計測を継続するため、位置情報の利用を継続します。 計測した位置情報は端末内に保存され、後述のヘルスケア連携を有効にした場合のみ、GPSルートを含むワークアウトとしてヘルスケアへ保存されます。

モーションセンサー

信号待ち等での自動停止・再開判定の補助、および走行状態の記録のために使用します。

ヘルスケア（Apple ヘルスケア）

ヘルスケア連携を有効にした場合に限り、次のとおりアクセスします。

  • 読み取り: カロリー計算の精度向上のため、許可された場合に体重を読み取ります。
  • 書き込み: 計測したライドのワークアウト（距離・消費カロリー・GPSルートを含む）をヘルスケアへ保存します。

ヘルスケアへ保存されたデータは、Apple社のヘルスケア機能・プライバシーポリシーに従って管理されます。

カレンダー（フルアクセス）

カレンダー連携を有効にした場合に限り、計測したライドの要約（時間・距離・平均速度・消費カロリー）をカレンダーへ予定として登録します。 登録済み予定の重複防止・更新・削除の判定のためにカレンダーを読み取りますが、位置情報を予定へ登録することはありません。 登録した予定は、ご利用のカレンダーの設定によってはiCloud等のカレンダーサービスへ同期される場合があります。

3. データのエクスポート

本アプリはCSV・GPX形式でのライドデータのエクスポート機能を備えています。エクスポートしたファイルには位置情報が含まれる場合があります。 エクスポート後、ご自身の判断で端末外・第三者へ共有された場合の当該データの管理は、共有先の責任となります。

4. データの削除

保存先ごとに、削除操作・アンインストールの影響範囲は次のとおり異なります。

アプリ内データ

ライドの削除操作を行うと、その記録は端末内のアプリ保存領域から削除され、本アプリの機能で元に戻すことはできません。本アプリを端末から削除（アンインストール）した場合も、端末内に保存されていた全ての記録が失われます。 ただし、本アプリのデータはiOSの標準的な端末バックアップ（iCloudバックアップやパソコンへのローカルバックアップ）の対象に含まれる設計のため、削除前に作成されたバックアップが残っている場合、そのバックアップをiOSの機能で復元するとアプリ内データも一緒に復元されることがあります（本アプリ自体による復元ではなく、iOSのバックアップ機能によるものです）。バックアップの管理・削除は、ご利用のバックアップ機能（iCloud設定等）から行ってください。

ヘルスケア・カレンダー（連携先）

ヘルスケア連携・カレンダー連携を有効にして同期済みのライドを削除する場合、本アプリはそれぞれ「連携先のデータも削除するか」を個別に確認します。 削除を選択しなかった場合、当該ライドの記録はヘルスケア・カレンダー側に残り続けます（アプリ内のライド削除やアンインストールでは自動的に消えません）。 ヘルスケア側のデータはヘルスケアアプリから、カレンダー側の予定はカレンダーアプリから、それぞれ個別に削除できます。

エクスポートファイル

CSV/GPXとして書き出し、共有・保存したファイルは本アプリの管理対象外です。アプリ内のライド削除・アンインストールでは削除されません。共有先での削除は、共有先の機能に従って行ってください。

5. 権限の確認・取り消し

位置情報・モーションとフィットネス・ヘルスケア・カレンダーへのアクセス許可は、iOSの「設定」アプリ（設定 > プライバシーとセキュリティ、または設定 > ヘルスケア > データアクセスとデバイス）からいつでも確認・取り消しできます。 許可を取り消すと、該当する計測・連携機能は利用できなくなりますが、既に端末内に保存済みのライド記録には影響しません（ヘルスケア・カレンダーに既に保存済みのデータも、許可の取り消しだけでは削除されません。削除する場合は上記4節の手順が必要です）。

6. 第三者提供

当方は、本アプリを通じて取得した情報を第三者へ提供・販売することはありません。

7. 本ポリシーの変更

本アプリの機能追加・変更に伴い、本ポリシーの内容を変更することがあります。重要な変更を行う場合は、本ページの内容を更新してお知らせします。
