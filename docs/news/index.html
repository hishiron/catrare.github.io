2026年9月21日 ・ Catrare Workbill ・ リリース

Catrare Workbill（稼働報告・請求書）を公開しました

フリーランス・個人事業主向けの稼働報告・請求書発行システム「Catrare Workbill（WORKBILL）」を公開しました。インストール不要・無料で、ブラウザから https://www.catrare-tech.jp/apps/workbill/ にアクセスしてご利用いただけます（現在のバージョンは 1.2.0 です）。

顧客・案件・契約を登録し、日々の稼働をカレンダーで入力すると、契約条件（精算幅・丸め・単価）に沿って報酬を自動計算します。月次の稼働報告書の作成・確定、請求書の作成・発行・改訂・入金管理、請求書の検索・印刷、月末の稼働予想やダッシュボードでの集計にも対応しています。確定した請求データは Catrare Ledger へ JSON で連携できます。

データはお使いのブラウザ内だけに保存され、サーバーへは送信されません。機能の詳細・画面のご紹介・技術スタックは、紹介ページ https://www.catrare-tech.jp/workbill/ をご覧ください。

消費税・源泉徴収の扱いなど税務に関わる設定は、契約内容に合わせてご確認のうえご利用ください。

2026年9月21日 ・ Catrare Ledger ・ リリース

Catrare Ledger（帳簿システム）を公開しました

個人事業主・フリーランス向けの帳簿システム「Catrare Ledger（LEDGER）」を公開しました。インストール不要・無料で、ブラウザから https://www.catrare-tech.jp/apps/ledger/ にアクセスしてご利用いただけます（現在のバージョンは 1.3.0 です）。

収入・経費・資産・証憑を、借方・貸方を意識せずに登録すると複式簿記の仕訳が自動で作られます。家事按分、固定資産の管理、証憑・出金伝票、仕訳帳・総勘定元帳・残高試算表・損益計算書・貸借対照表の表示、白色申告の収支内訳書や青色申告決算書へ転記するための集計の出力、年度締めとバックアップまで対応しています。

データはお使いのブラウザ内だけに保存され、サーバーへは送信されません。機能の詳細・画面のご紹介・技術スタックは、紹介ページ https://www.catrare-tech.jp/ledger/ をご覧ください。

本システムは記帳・集計を補助するツールで、税務判断を自動化するものではありません。家事按分や資産の扱い、控除の適用などは国税庁の資料・税務署・税理士等でご確認ください。
