iPhone Game

にゃんくらいむ

iPhoneを傾けて猫を操作し、床から床へ跳び移りながら月を目指す、縦スクロールのジャンプアクションゲームです。無料で遊べます（広告表示あり）。

あそびかた・サポート

Features

傾けるだけのかんたん操作で、家から月まで登っていきます。

傾けて操作、ジャンプは自動

端末を左右に傾けると、猫がその向きへ動きます。ジャンプは床に着地すると自動で行うので、片手で遊べます。

家から月まで9つのステージ

2階建ての家から、ビル群・山・雲の上・宇宙へと登っていきます。エベレストから先は上へ行くほど重力が弱くなり、ふわりと跳ぶようになります。

いろいろな床

動く床・消える床・割れる床・バネ床・回転する床・氷の床など、ステージが進むほど床の種類が増えていきます。

アイテムとじゃまなもの

高く跳べるジャンプブーストや、落ちても跳ね返される無敵シールドが登場します。猫じゃらしにふれると引き寄せられるので気をつけましょう。

気球と宇宙船

気球に乗るとゆっくり上昇し、宇宙船に乗ると一気に上へ運んでもらえます。

体力とコンティニュー

ジャンプするたびに体力が減り、キャットフードと水のセットで満タンに戻ります。富士山から先のステージを越えるとコンティニューの回数が増え、落ちてもその場から再開できます。
