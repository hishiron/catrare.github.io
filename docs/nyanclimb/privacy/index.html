Privacy Policy

ニャンクライム
プライバシーポリシー

カトレアテック（以下「当方」）が提供するiOSアプリ「ニャンクライム」（以下「本アプリ」）における、 個人情報・端末情報の取り扱いについて説明します。

1. 基本方針

本アプリは、猫がジャンプで床を登り月を目指すゲームです。ハイスコアや設定などのゲームデータは本アプリを利用する端末内にのみ保存され、 当方が運営するサーバーへ送信することはありません。本アプリにはアカウント登録・ログイン機能はなく、氏名・メールアドレス・電話番号などの情報は取得しません。 当方は独自のアクセス解析も行いません。

ただし、本アプリは広告を表示するため、Google社の広告サービス（Google AdMob）と同意管理サービス（Google User Messaging Platform）を利用しています。 そのため、広告の配信に必要な範囲で、端末に関する情報がGoogle社へ送信されます。詳細は3節から6節を参照してください。

2. 端末内に保存する情報と利用目的

次の情報を、端末内の本アプリの保存領域に保存します。いずれも当方サーバーへは送信されず、広告事業者等の第三者へも送信しません。

  • ハイスコア（最高到達高度・達成日時）: ゲーム画面でのハイスコア表示のため
  • 設定（効果音・BGMのオン/オフ）: 次回以降の起動時に設定を引き継ぐため
  • 起動時広告を最後に表示した日: 起動時広告が1日に何度も表示されないよう、表示頻度を制御するため

プレイ中の操作内容・プレイ時間・スコアの詳細などは、記録も送信もしません。

3. 広告の配信について（Google AdMob）

本アプリは、ゲームオーバー後に広告を視聴してコンティニューできる「リワード広告」と、アプリの起動時に表示される「起動時広告」を、Google社のAdMobを通じて表示します。 広告の配信・表示・不正防止・効果測定のため、Google社の仕様に従い、次のような情報が本アプリからGoogle社へ送信されることがあります。

  • 広告ID（IDFA）: 「トラッキング」の許可（5節）をいただいた場合のみ
  • IPアドレス（大まかな地域の推定に用いられることがあります）
  • 端末の機種・OSのバージョン・言語設定・本アプリのバージョン等の端末・アプリに関する情報
  • 広告の表示・クリック・視聴完了など、広告の利用状況に関する情報

一方で、ハイスコア・設定値・プレイ中の操作内容・プレイ時間などのゲームデータは、Google社へ送信しません。

Google社によるこれらの情報の取り扱いは、Google社のプライバシーポリシーに従います。詳細は次のページを参照してください。

  • Google プライバシー ポリシー
  • Google のサービスを使用するサイトやアプリからの情報の Google による使用

4. 同意の管理（Google User Messaging Platform）

欧州経済領域（EEA）・英国・スイスなど、広告に関する同意の取得が法令で求められる地域では、本アプリは起動時にGoogle社の同意管理サービスを通じて同意の確認を行い、同意の内容に従って広告を配信します。 同意が得られていない間は、広告の読み込みを行いません。

同意の内容を後から確認・変更したい場合は、本アプリの設定画面に表示される「プライバシー選択」から変更できます（同意の再確認が必要な地域でのみ表示されます）。

5. トラッキングの許可（App Tracking Transparency）

本アプリは、広告ID（IDFA）を用いて広告のパーソナライズ等を行うため、初回の広告表示の前にiOSの「トラッキング」の許可をお願いするダイアログを表示することがあります。

  • 許可した場合: 広告ID（IDFA）が広告の配信に利用され、パーソナライズされた広告が表示されることがあります。
  • 許可しなかった場合: 広告ID（IDFA）は利用されず、パーソナライズされない広告が表示されます。広告の表示自体や、本アプリで遊べる内容は変わりません。

許可の設定は、iOSの「設定」アプリ（設定 > プライバシーとセキュリティ > トラッキング）からいつでも変更できます。

6. 第三者提供・外部への送信

本アプリは、広告の配信のため、3節に記載した情報を次の事業者へ送信します。

  • 送信先: Google LLC（Google AdMob・Google User Messaging Platform）
  • 送信される情報: 3節に記載した情報（広告ID・IPアドレス・端末とアプリの情報・広告の利用状況）、および同意の状況
  • 利用目的: 広告の配信・表示、不正利用の防止、広告の効果測定、同意の管理

上記のほか、当方は、本アプリを通じて取得した情報を第三者へ提供・販売することはありません。

7. データの削除

  • ハイスコア: 本アプリの設定画面の「ハイスコアをリセット」から削除できます。削除後は元に戻せません。
  • 端末内のすべてのデータ: 本アプリを端末から削除（アンインストール）すると、端末内に保存されていたデータは失われます。ただし、iOSの標準的な端末バックアップ（iCloudバックアップやパソコンへのバックアップ）が残っている場合、そのバックアップをiOSの機能で復元するとデータも復元されることがあります。バックアップの管理・削除は、ご利用のバックアップ機能から行ってください。
  • Google社が保有する情報: 当方では削除できません。Google社のプライバシーポリシーに従って管理されます（3節）。

8. 本ポリシーの変更

本アプリの機能追加・変更（ゲーム内課金やオンライン機能の追加など）や、利用する広告サービスの変更に伴い、本ポリシーの内容を変更することがあります。 重要な変更を行う場合は、本ページの内容を更新してお知らせします。
