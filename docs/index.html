システム開発と運用を、
現場に合うかたちで。

カトレアテックは、業務システムの開発、既存システムの改善、データ・AIの業務活用を支援します。課題の整理から設計・実装・運用改善まで、実務に合わせて取り組みます。

サービス

新しい仕組みづくりから、今あるシステムの改善まで。状況を伺い、必要な対応を一緒に整理します。

  • システム開発

    手作業を減らしたい。業務に合うツールを作りたい。

    業務の流れや必要な機能を整理し、Webシステムや業務支援ツールを設計・開発します。使い始めた後の保守や改善も見据えて実装します。

    対応範囲：要件整理 / 設計 / 実装 / テスト

  • 既存システムの改善

    保守しにくい。運用負荷が高い。改修の進め方が分からない。

    現在のシステムと運用を確認し、課題と優先順位を整理します。保守性や運用のしやすさを考慮しながら、必要な改修を進めます。

    対応範囲：現状調査 / 課題整理 / 改善方針 / 改修

  • データ・AIの業務活用

    集計や確認作業を効率化したい。データを判断に使いたい。

    ダッシュボードやAIを用いた業務支援ツールを、実際の作業に合わせて設計・開発します。技術の導入そのものではなく、日々の業務で使える形を重視します。

    対応範囲：データ整理 / 可視化 / 業務支援ツール / 既存業務への組み込み

支援内容・期間・対応時間は、状況とご希望を伺ったうえで個別に相談します。

プロフィール

城野しろの 秀峰ひでみね

カトレアテック／個人事業主

2000年からソフトウェアエンジニアとして約26年、インターネットサービスのシステム開発・運用に携わってきました。社内情報システムの開発と部門運営、大規模ライブ動画配信基盤の再構築を技術リード兼マネージャーとして担当したほか、広告データの分析基盤や、生成AIを活用した業務支援ツールの開発、システム・データの構想策定支援にも取り組んできました。現在はカトレアテックとして、課題の整理から設計・実装・運用改善まで、実務に根ざした技術支援を行っています。

得意分野
システム開発、既存システムの改善、運用を見据えた設計・実装。
大切にしていること
ホスピタリティを持って仕事に取り組むことを大切にしています。ご依頼をいただいたときは「できない」と言う前に、どうすれば実現できるかを考えます。関係者と密に連携しながら技術的な課題を一つずつ解決し、課題の整理だけで終わらせず、実際に使える形まで手を動かします。
